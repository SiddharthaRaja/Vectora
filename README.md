# Vectora — Retrieval-Augmented Generation (RAG) System

Vectora is a Retrieval-Augmented Generation (RAG) application that enables efficient question answering over custom data by combining vector search with large language models.

---

## 🚀 Overview

This project implements a complete RAG pipeline:

1. **Ingestion Pipeline**  
   Processes documents and converts them into embeddings

2. **Vector Storage**  
   Stores embeddings in a vector database for semantic search

3. **Retrieval**  
   Fetches relevant chunks based on user queries

4. **Generation**  
   Uses an LLM to generate context-aware answers

---

## 🧠 Features

- End-to-end RAG pipeline
- Semantic search using vector embeddings
- Modular architecture (ingestion, retrieval, generation)
- Local database + vector storage support
- Extensible for APIs, UI, or deployment
